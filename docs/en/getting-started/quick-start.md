# QuickStart

Kosame is a database framework based on Drizzle.
Because it is based on Drizzle, it can be integrated into existing systems without disrupting them.

## Kosame install

<a href="installation.md">About install <-</a>

### bun

```bash
bun add kosame
```

## Installing Drivers

### node-postgres

```bash
bun add drizzle-orm@^0.45.2 pg
bun add -D drizzle-kit@^0.45.2 @types/pg
```
