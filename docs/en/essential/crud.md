# CRUD

Kosame provides its own CRUD operations.

## How to Write CRUD Operations

### Syntax Common to `add()` and `find()`

To use it, first access `context`, then specify the name of the table you want to work with (in this case, `users`), and finally enter the method you want to call.

### add()

The `add()` method is used to insert values into the database.
Pass the column values as an object to the `add()` method.
The `add()` method returns a Model instance that includes the values generated by the database.
