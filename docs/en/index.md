# Kosame

Kosame is a database framework that brings model-driven development to Drizzle.
It keeps Drizzle's SQL-like syntax and its lightweight design while making development easier, and it can be applied to DB schemas you have already built with Drizzle. Where things get complex, Kosame's model-driven development really shows its strength.
