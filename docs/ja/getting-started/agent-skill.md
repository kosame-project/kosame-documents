# エージェント用スキル

KosameにはClaude Codeなどのコーディングエージェントに、Kosameの書き方を教えるスキルが同梱されています。

## スキルのインストール

`kosame`をインストールしたあと、プロジェクトで次のコマンドを実行します。

```bash
npx kosame skills install --claude-md
```

スキルが`.claude/skills/kosame`にコピーされ、`CLAUDE.md`にスキルを指す1行が追加されます。
`CLAUDE.md`を変更したくない場合は`--claude-md`を付けずに実行してください。追加する1行が表示されるので、`CLAUDE.md`や`AGENTS.md`に自分で書くことができます。

## スキルの更新

スキルはパッケージと一緒に更新されます。`kosame`をアップグレードしたあと、同じコマンドをもう一度実行すると、インストール済みのスキルが置き換わります。

## スキルの中身

スキルには、守るべきルール、例、既知の制限をまとめた短い`SKILL.md`と、このドキュメントの英語ページを入れた`references`フォルダがあります。エージェントは必要なときだけ、`references`を読みます。
