# What is Kosame?

KosameはDrizzleをベースにしたデータフレームワークです。
KosameはツールとしてのDrizzleをより運用しやすく設計に近い開発をできるようにするために開発されたフレームワークです。
Drizzleの軽量さや薄さを残し、フレームワークとしての決まりを提供します。

## Drizzleの哲学

Drizzleの哲学として既存のORMをデータフレームワークと呼んでいます。
DrizzleはHeadless ORMと謳っています。これはDrizzleが既存のORMのプロジェクトに干渉的な部分を削ぎ落とした哲学を持っています。

### なぜdata-frameworkなのか?

Kosameが決まり(ガイドライン)を提供する理由は、ORMには決まり(ガイドライン)があるべきと考えているからです。
決まり(ガイドライン)がなければSQLで良いよという考えを持っています。
書き方や型などは、Kyselyなどの外部ツールでカバー出来てしまいます。
それでもカバーしきれない決まり(ガイドライン)を提供する必要があると思い、Kosameはdata-frameworkとしての決まり(ガイドライン)を提供します。
