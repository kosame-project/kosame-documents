  KosameはDrizzleをベースにmodel駆動の開発を提供するデータベースフレームワークです。
  Drizzleのsqlライクな書き方、Drizzleの軽量さを残しより開発しやすくすることができます、そして既存のDrizzleで構築されたDBスキーマにも適用させることができ複雑になる場合などの使用ではKosameのmodel駆動の開発の力を強く発揮します。
